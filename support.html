Quick Help

Why is recording not starting?

Make sure you are on a normal website page, not an internal browser page such as edge:// or chrome://. Also confirm that screen, microphone, and camera permissions were granted if needed.

Why does a recording appear in history but not play?

This can happen if metadata exists but the local video file is missing. Use the Repair Missing button in the dashboard to clean broken entries.

Where are recordings stored?

Recordings are stored locally in your browser profile using extension storage and IndexedDB.

Does EdgeCam Pro upload my recordings automatically?

No. Recordings are stored locally by default and are not uploaded automatically without your explicit action.

Frequently Asked Questions

Which browsers are supported?

EdgeCam Pro is built primarily for Microsoft Edge. Other Chromium-based browsers may support most features, but Microsoft Edge is the main target platform.

Can I record screen and webcam at the same time?

Yes. EdgeCam Pro supports screen + webcam combined recording with webcam overlay.

Can I record system audio and microphone together?

Yes, depending on browser and OS support. You can enable both sources from the popup or settings.

Can I delete old recordings?

Yes. You can remove individual recordings or bulk-delete entries from the dashboard.

Bug Reports

If you report a bug, please include as much detail as possible so we can help faster.

  • Browser name and version
  • Operating system
  • What type of recording you attempted
  • What happened instead of the expected result
  • Whether screen, webcam, or audio permissions were enabled
  • Any visible error messages
Tip: If a recording appears in history but will not play, mention whether it was created before or after the latest extension update.
